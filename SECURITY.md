# Security Policy

## Supported version

Security fixes are applied to the current `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose user data or enable abuse. Use GitHub's **Private vulnerability reporting / Security advisory** flow for this repository when available.

Include the affected file or feature, reproduction steps, expected impact, and any mitigation you have already tested. Reports that concern browser storage should also mention the browser and whether the issue reproduces in a clean profile.
